# Image sources

`lumberjack-hat.png` is the OSRS Wiki's [Lumberjack hat](https://oldschool.runescape.wiki/w/File:Lumberjack_hat.png) inventory icon, embedded locally for Through the Vampire Mist.

`temple-trekking-tome.png` is the OSRS Wiki's [Slayer tome (blue)](https://oldschool.runescape.wiki/w/File:Slayer_tome_(blue).png) inventory icon. Both generators support embedding it for experience tome requirements; it replaces the nonexistent `Tome_of_experience_(1).png` image.

`corrupted-hunllef.png` is the OSRS Wiki's [Corrupted Hunllef](https://oldschool.runescape.wiki/w/File:Corrupted_Hunllef.png) image. It provides The Red Labyrinth's distinct boss background.

`crystal-armour-seed.png` is the OSRS Wiki's [Crystal armour seed](https://oldschool.runescape.wiki/w/File:Crystal_armour_seed.png) inventory icon, used for The Red Labyrinth's sprite. Both images are embedded locally in the generated board.

`royal-titans.png` is the OSRS Wiki's [Fighting Royal Titans](https://oldschool.runescape.wiki/w/File:Fighting_Royal_Titans.png) image, downloaded from https://oldschool.runescape.wiki/images/Fighting_Royal_Titans.png.

`blood-moon.png` is the OSRS Wiki's [Fighting the Blood Moon](https://oldschool.runescape.wiki/w/File:Fighting_the_Blood_Moon.png) image, downloaded from https://oldschool.runescape.wiki/images/Fighting_the_Blood_Moon.png.

`dual-macuahuitl.png` is the OSRS Wiki's [Dual macuahuitl detail](https://oldschool.runescape.wiki/w/File:Dual_macuahuitl_detail.png) image, downloaded from https://oldschool.runescape.wiki/images/Dual_macuahuitl_detail.png.

`vorkath.png` is the OSRS Wiki's [Vorkath](https://oldschool.runescape.wiki/w/File:Vorkath.png) image, downloaded from https://oldschool.runescape.wiki/images/Vorkath.png.

`vorkaths-head.png` is the OSRS Wiki's [Vorkath's head](https://oldschool.runescape.wiki/w/File:Vorkath%27s_head.png) icon, downloaded from https://oldschool.runescape.wiki/images/Vorkath%27s_head.png.

Old School RuneScape game imagery is copyright Jagex Ltd. Both board generators embed these local images in the SVG so they remain available without external image requests.

Halloween frame assets from the OSRS Wiki:

- `spooky-pumpkin-lantern.png`: [Spooky pumpkin lantern detail](https://oldschool.runescape.wiki/w/File:Spooky_pumpkin_lantern_detail.png).
- `pumpkin.png`: [Pumpkin detail](https://oldschool.runescape.wiki/w/File:Pumpkin_detail.png).
- `cobweb.png`: [Web](https://oldschool.runescape.wiki/w/File:Web.png).

`halloween-frame.svg` is the shared decorative SVG fragment used by both generators. The generators substitute image data and board-height coordinates for its `{{TOKEN}}` placeholders.
